## Sync Decision Guide

| Content | Write to | Method | When |
|---------|----------|--------|------|
| MEMORY.md changes | SQLite chunks + workspace file | sqlite3 INSERT + cp/echo | Every sync |
| USER.md changes | Workspace USER.md | Direct file write | Only when USER.md changed |
| SOUL.md | Neither | Skip — one-shot only | Never |
| New skills | Both SKILLs/ dirs | symlink or copy | On first detection |
| Skills removed | Both SKILLs/ dirs | rm | On detection |
