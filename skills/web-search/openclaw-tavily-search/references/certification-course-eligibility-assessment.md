# Certification/course eligibility assessment notes

Use when the user asks whether a course/certificate satisfies a stated job/application requirement (e.g. "讀完算符合具ISO20000，資訊科技範疇相關的培訓證書嗎").

## Workflow
1. Extract the official course page first (not just search snippets). Capture exact course title, standard/version, hours, assessment, issuer, and certificate wording.
2. Cross-check the required standard/credential with authoritative sources (prefer ISO/vendor official pages) to establish the exact domain and naming.
3. Compare exact-match vs broader-category match:
   - Exact standard required: ISO/IEC 20000-1 ≠ ISO/IEC 27001.
   - Broader category required: ISO/IEC 27001 can plausibly count as an IT / cybersecurity / information security related training certificate.
4. Answer conditionally based on the wording of the requirement; do not overclaim.
5. Provide safe wording the user can put on forms/CV.

## Example pattern: ISO 27001 course vs ISO 20000 requirement
- [training provider] course `MG17.1-06-2026-C` = **推行 ISO/IEC 27001:2022 工作坊**.
- It issues a **[training provider] 修業證書** if attendance >=80%, class exercises complete, and assessments pass.
- Contents: ISMS, ISO 27000 series, ISO 27001 clauses, Annex A, information security risk management, SOA, certification arrangements.
- ISO/IEC 20000-1 is **IT service management / Service Management System (SMS)**, covering planning, design, transition, delivery and improvement of services.
- ISO/IEC 27001 is **information security management / ISMS**.

## Recommended answer stance
- If requirement says **"具 ISO20000 培訓證書"**: answer **No / not exact match**.
- If requirement says **"具 ISO20000 或資訊科技範疇相關培訓證書"**: answer **likely yes for the broader IT-related training part**, but not as ISO20000.
- If requirement says **"資訊科技範疇相關培訓證書"**: answer **yes, reasonably fits**, because ISO27001 is information security / cybersecurity management.

## Safe wording
Do not write: `具 ISO20000 證書`.
Write: `完成a regional productivity and technology transfer centre《推行 ISO/IEC 27001:2022 工作坊》修業證書，內容涵蓋資訊安全管理體系（ISMS）、風險評估及 ISO 27001 控制措施。`

## Pitfalls
- Do not treat all ISO standards as interchangeable.
- Do not call a course completion certificate a professional certification unless the official page says so.
- If eligibility affects an official application, advise confirming with the receiving body because acceptance depends on their interpretation of "相關".
